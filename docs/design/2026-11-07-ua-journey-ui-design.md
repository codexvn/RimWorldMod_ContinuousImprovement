## A. 产品范围摘要（已确认的结论）

本 Mod 在研究树最右侧新增一项可无限循环研究的科技「全局工作速度循环科技」。每完成一次研究记为一层：层数随存档持久保留，研究进度清零、成本乘以 1.25 后重新可研究，当前项目自动重设为该协议。每层为全体玩家阵营单位（含机械体）叠加全局工作速度加成，加法（1+0.1N）与乘法（1.1^N）两种公式在 Mod 设置中切换，设置保存在全局配置、切换即时生效。

| 范围 | 内容 |
|------|------|
| 做什么 | 循环科技本体、层数持久化、全局工作速度加成、公式切换设置、完成通知 |
| 不做什么 | 不改研究树布局与其他科技、不做浮动 HUD、不做游戏内历史曲线界面（由 README 与 HTML 图表承担）、不提供逐层参数自定义 |

三类角色使用本功能：人类玩家（手动游玩，核心角色）、AI 代玩代理（经 RimWorldMCP 工具驱动）、开发者（dev 模式验证机制）。

关键决策与理由：其一，「代谢」在引擎中是生理容量（PawnCapacityDef）而非属性，无法走 StatPart，改挂消耗率收口方法——该方法已串联床铺、健康、基因、哺乳等全部修正，倍率作用于最终值语义完整。其二，「射速」无直接属性，取瞄准时长乘数 `AimingDelayFactor` 作为等价物（瞄准更短=单位时间射出更多），连发间隔不受影响，属已知边界。其三，研究速度循环明确不做：研究速度已以全局工作速度为因子，单独叠加会形成双重自举。其四，六项科技共用同一成本曲线（3000 × 1.25^N）与同一全局加法/乘法设置，设置页提供全部科技的状态总表。
